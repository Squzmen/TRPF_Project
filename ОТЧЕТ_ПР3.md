## Доработка индивидуального проекта

Продолжен проект ПР2 в том же репозитории:
`https://github.com/Squzmen/TRPF_Project`. Основные сущности представлены
классами `Event` (мероприятие), `User` (посетитель) и `Plan` (запись в план).
Каждый класс имеет атрибуты, конструктор `__init__`, методы и строковое
представление `__str__`. `Plan` содержит ссылки на объекты `Event` и `User`;
метод `cancel()` помечает запись отмененной, оставляя ее в истории и освобождая
место. Поиск, фильтрация, сортировка и функции хранения остаются операциями
над коллекциями, а проверки ПР1 работают с объектами. Показано применение
`@classmethod` и `@staticmethod`; искусственного наследования нет.

Модули `models/`, `events.py`, `plans.py`, `storage.py`, `utils.py`, `main.py`
разделяют модель, обработку коллекций, хранение и интерфейс. Добавлен файл
`data/users.json`; `events.json` по-прежнему содержит каталог, `plans.json`
хранит ID связанных объектов и признак отмены. При чтении JSON создаются
объекты и восстанавливаются связи; прежние записи формата ПР2 читаются без
потери данных. При записи объекты преобразуются обратно в JSON.

## Результат работы

Сохранены пункты меню ПР2, проверка условий, запись, отмена, поиск,
сортировка и статистика; добавлены просмотр/создание посетителей и добавление
событий. Отмененные записи сохраняются, но не занимают место. Основные методы
и функции имеют аннотации типов. Тесты проверяют создание объектов, связь
объектов, запрет повторной записи, отмену, загрузку старого JSON, сохранение
нового JSON и консольное меню. На Python 3.13 выполнено 23 теста `pytest`:
все прошли; проверка `flake8 .` замечаний не выявила.

## Вывод

Функциональная версия проекта ПР2 преобразована в объектную модель без потери
основных возможностей и с совместимостью старых данных. Материалы Яндекс
Практикума перечислены со слов студента без независимой проверки. Отладка в
IDE и отправка изменений в Git пользователем выполняются отдельно.
