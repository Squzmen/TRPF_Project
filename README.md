# Система планирования культурного досуга

## Назначение

Приложение помогает пользователю подобрать культурное мероприятие и добавить его в личный план досуга. На первом этапе программа проверяет конкретное мероприятие по возрастному ограничению, интересующей категории, доступному бюджету, дате и наличию свободных мест.

## Целевая аудитория

Городские жители, которые посещают театры, музеи, выставки, концерты и другие культурные события и хотят заранее планировать свободное время с учетом личных предпочтений и бюджета.

## Предметная область

Предметная область охватывает поиск и планирование культурного досуга. Пользователь задает свои параметры, а система сопоставляет их с характеристиками мероприятия и сообщает, подходит ли событие для посещения. В дальнейшем приложение сможет хранить каталог событий и персональные планы нескольких пользователей.

## Основные сущности

- **Пользователь** — посетитель с именем, возрастом, предпочтениями и доступным бюджетом.
- **Мероприятие** — культурное событие с названием, стоимостью билета, возрастным ограничением и доступностью мест.
- **Дата** — день проведения мероприятия, необходимый для календарного планирования.
- **Категория** — тип культурного события: театр, музей, выставка, концерт и другие.

## Основные функции

- проверка соответствия возраста пользователя ограничению мероприятия;
- проверка соответствия мероприятия интересующей пользователя категории;
- проверка достаточности бюджета для покупки билета;
- определение временного статуса мероприятия по его дате;
- формирование итоговой рекомендации с учетом всех проверок.

## Начальный сценарий ПР1

В `main.py` задано демонстрационное мероприятие — спектакль «Гамлет». Пользователь вводит имя, возраст, интересующую категорию и бюджет. Программа преобразует введенные значения в нужные типы, выполняет проверки и сообщает, можно ли добавить мероприятие в план досуга.

В реализации используются простые типы данных, операции сравнения, преобразование типов, ветвления, функции и объект `date` из стандартного модуля `datetime`. Коллекции, циклы и классы намеренно не применяются: они будут добавлены на следующих этапах проекта.

## Запуск

Требуется Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python main.py
```

Пример данных для успешной проверки:

```text
Имя: Анна
Возраст: 20
Категория: театр
Бюджет: 2000
```

## План развития

На следующих этапах планируется:

- расширить консольную программу: добавить каталог мероприятий, несколько сценариев, модули, файлы, обработку исключений и типизацию;
- представить основные сущности в виде классов с применением ООП;
- разработать веб-приложение на Django;
- подключить базу данных и реализовать связи между пользователями, мероприятиями, категориями и датами;
- реализовать создание, просмотр, изменение и удаление данных;
- добавить регистрацию, аутентификацию, авторизацию и персональный календарь пользователя;
- разработать REST API;
- добавить автоматизированные тесты на Pytest;
- контейнеризировать приложение с помощью Docker;
- настроить CI/CD.
