## 2. Цель работы

Перевести веб-интерфейс, созданный в ПР5, с формирования HTML в Python-функциях на систему шаблонов Django, сохранив предметную область, JSON-хранилище и работоспособность проекта.

## 3. Выполненные материалы Яндекс Практикума

В разделе 04 «Основы веб-разработки» выполнены тема «HTML и шаблоны Django» и «Финальный проект спринта Блогикум». Все задания и уроки выполнены полностью.

## 4. Доработка индивидуального проекта

Создан базовый шаблон templates/base.html (подключение Bootstrap, собственного CSS и JS, блоки title и content, подвал) и включаемый фрагмент навигации. Страницы приложений наследуют base.html через {% extends %}; карточка мероприятия, статус записи вынесены в includes и подключаются через {% include ... with %}. Шаблоны homepage, catalog и planner расположены в templates/<приложение>/.

Данные передаются через контекст (render()); в шаблонах использованы циклы {% for ... empty %}, условия {% if %}, фильтры length, default, date, floatformat. Жёстко заданные адреса заменены именованными маршрутами с пространствами имён ({% url 'catalog:detail' event.id %}). Подключены статические файлы: style.css, main.js и логотип ({% load static %}). Функция page() и строки HTML из views.py удалены.

## 5. Результат работы

- HTML отделён от Python-кода, страницы строятся на шаблонах;
- реализованы наследование шаблонов и включаемые фрагменты;
- применены именованные URL с app_name и статические файлы;
- добавлены собственные стили, скрипт и логотип проекта;
- тесты веб-части обновлены под шаблоны, консольная часть не затронута.
