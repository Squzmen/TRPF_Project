## 2. Цель работы

## 4. Доработка индивидуального проекта

Спроектирована база данных SQLite из трёх таблиц: events, users, plans. В sql/schema.sql заданы первичные ключи, внешние ключи plans → events и plans → users, ограничения CHECK и индексы. Скрипт db/import_json.py переносит данные из JSON в базу (executemany, параметризованные запросы, откат при ошибке), db/database.py содержит подключение с PRAGMA foreign_keys = ON.

В sql/queries.sql подготовлено 13 запросов с комментариями: SELECT, WHERE, BETWEEN, ORDER BY, подзапросы, JOIN и LEFT JOIN, COUNT, SUM, AVG, GROUP BY, HAVING. Запросы подключены к страницам: список мероприятий с фильтром по категории, поиск по датам и цене, подбор мероприятий для посетителя, список активных записей, страница статистики. Параметры передаются через «?», защита от SQL-инъекций проверена тестами. JSON-хранилище и консольная версия сохранены; описание базы добавлено в README.md.

## 5. Результат работы

- создана и заполнена база данных data/culture.sqlite (5 мероприятий, 7 посетителей, 6 записей);
